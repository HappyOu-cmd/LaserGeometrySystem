# Проверка линейного энкодера Modbus RTU

Диагностическая программа: `encoder_modbus_test_gui.py`.

Она работает отдельно от Laser Geometry System и предназначена для проверки энкодера до интеграции в основную программу.

## Параметры обмена

| Параметр | Значение |
|---|---:|
| Порт по умолчанию | `/dev/ttyUSB0` |
| Скорость | 9600 бод |
| Биты данных | 8 |
| Чётность | отсутствует (`N`) |
| Стоповые биты | 1 |
| Адрес устройства | 0 |
| Функция чтения | `0x03` |
| Регистры положения | 0–1 |
| Функция калибровки | `0x10` |
| Регистр калибровки | 49 |
| Значение калибровки | 1 |

Адрес 0 является нестандартным для отвечающего Modbus RTU Slave: обычно он используется как broadcast без ответа. Поэтому программа формирует и разбирает RTU-кадры напрямую и позволяет проверить фактическое поведение энкодера.

## Подключение RS-485

При выключенном питании соедините:

```text
энкодер A / D+  → преобразователь A / D+
энкодер B / D-  → преобразователь B / D-
GND             → GND, если это предусмотрено схемой оборудования
```

Если устройство не отвечает, сначала проверьте документацию преобразователя и попробуйте поменять A/B местами: обозначения разных производителей иногда противоположны.

## Права на serial-порт

Проверьте наличие порта:

```bash
ls -l /dev/ttyUSB0
```

Если пользователь не входит в группу `dialout`:

```bash
sudo usermod -aG dialout "$USER"
```

После этого необходимо выйти из пользовательской сессии и войти снова. Временный запуск через `sudo` не рекомендуется.

## Запуск

Основная Laser Geometry System должна быть остановлена, если она использует тот же `/dev/ttyUSB0`:

```bash
sudo systemctl stop laser_geometry.service 2>/dev/null || true
systemctl --user stop laser_geometry.service 2>/dev/null || true
```

Запустите тестовую программу:

```bash
cd /home/robopes_perm/Laser/LaserGeometrySystem
./.venv/bin/python encoder_modbus_test_gui.py
```

В поле порта уже указано `/dev/ttyUSB0`. Нажмите **«Запустить»**.

## Что показывает интерфейс

- положение в миллиметрах;
- фактическую частоту успешного опроса;
- полное 32-битное значение;
- младшее и старшее 16-битные слова;
- количество успешных и всех запросов;
- последний переданный и принятый RTU-кадр;
- график положения;
- ошибки timeout, CRC, функции и адреса.

Расчёт положения:

```text
raw = регистр_0 + регистр_1 × 65536
положение_мм = raw / 1000
```

## Ожидаемый запрос чтения

```text
00 03 00 00 00 02 C5 DA
```

Ожидаемый ответ имеет 9 байт:

```text
00 03 04 LL LL HH HH CRC CRC
```

Здесь `LL LL` — значение регистра 0, а `HH HH` — значение регистра 1. Внутри каждого Modbus-регистра старший байт передаётся первым.

## Калибровка

Кнопка **«Калибровать ноль»** отправляет:

```text
00 10 00 31 00 01 02 00 01 6E 21
```

Перед отправкой программа запрашивает подтверждение.

Если энкодер отвечает на адрес 0, GUI покажет подтверждённую калибровку. Если ответа нет, GUI сообщит, что команда отправлена без ответа — такое поведение допустимо для стандартного broadcast-адреса 0. Результат в этом случае проверяется по последующим значениям положения.

## Частота опроса

Программа не добавляет искусственную задержку между успешными запросами, но соблюдает обязательный интервал Modbus RTU в 3,5 символа. Максимальная реальная частота будет показана в карточке **«Частота опроса»** и зависит от времени ответа энкодера и USB-RS485 преобразователя.

## Интеграция в Laser Geometry System

Тестовый GUI по умолчанию продолжает использовать `/dev/ttyUSB0`. В основной программе энкодер опрашивается через отдельный `/dev/ttyUSB1` постоянным фоновым потоком.

Результаты публикуются в Holding-регистрах Modbus TCP:

| Регистры | Значение |
|---|---|
| 40584–40585 | Положение в мм, Float32: старшее слово / младшее слово |
| 40586 | Состояние: `0` offline, `1` online |

При потере связи `40586` становится равным `0`, но последнее корректное положение в `40584–40585` сохраняется. Ошибки порта, timeout, CRC и некорректные кадры не останавливают основную программу и не переводят автомат измерений в состояние ошибки.

Сообщения о подключении и отключении энкодера выводятся только в состоянии `IDLE`, например:

```text
[IDLE] Линейный энкодер подключен; последнее измеренное значение: 135.732 мм
[IDLE] Линейный энкодер отключен; последнее измеренное значение: 135.732 мм
```
